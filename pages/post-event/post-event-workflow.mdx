# Post-Event Workflow

<PageInfo
  purpose="The post-event period is critical for maintaining community momentum and improving future events. This workflow ensures nothing is missed between the last attendee leaving and the team formally closing out the event."
  owner="Lead Organizer coordinates; each item below has a natural team owner as noted."
  time="Runs in stages from 48 hours after the event through 1 month after."
/>

## Within 48 hours

### Thank you communications
<Checklist id="postevent-thanks">
- [ ] Send thank you email to all attendees (owner: Marketing & Communications Lead)
- [ ] Send personalized thank you to speakers (owner: Program Lead)
- [ ] Send thank you to sponsors with impact metrics (owner: Sponsorship Lead, using [sponsorship/sponsor-lifecycle-and-fulfillment.md](../sponsorship/sponsor-lifecycle-and-fulfillment))
- [ ] Send thank you to volunteers (owner: Volunteer Coordinator)
- [ ] Send thank you to venue and vendors (owner: Logistics Lead)
- [ ] Send thank you to community partners (owner: Partnerships & Outreach Lead)
</Checklist>

### Content publishing
<Checklist id="postevent-content">
- [ ] Publish event photos to social media
- [ ] Share photo album link with attendees
- [ ] Post thank you message on all social channels
- [ ] Tag sponsors, speakers, and partners in posts
- [ ] Share attendee testimonials
</Checklist>

Templates: [marketing-and-communications/social-media-playbook.md](../marketing-and-communications/social-media-playbook).

## Within 1 week

### Recap content
<Checklist id="postevent-recap">
- [ ] Publish event recap blog post
- [ ] Share speaker presentation slides (if approved)
- [ ] Upload session videos to YouTube (if recorded)
- [ ] Create event highlights reel
- [ ] Send newsletter with event summary
</Checklist>

Framework: [marketing-and-communications/content-and-articles-guide.md](../marketing-and-communications/content-and-articles-guide) "Event Recap."

### Feedback collection
<Checklist id="postevent-feedback">
- [ ] Send attendee feedback survey
- [ ] Send speaker feedback survey
- [ ] Send sponsor feedback survey
- [ ] Send volunteer feedback survey
- [ ] Compile feedback results
</Checklist>

## Within 2 weeks

### Internal review
<Checklist id="postevent-review">
- [ ] Schedule post-event team meeting
- [ ] Review feedback survey results
- [ ] Document what worked well
- [ ] Document what needs improvement
- [ ] Analyze budget vs. actual spending (see [planning/budget-and-finance-principles.md](../planning/budget-and-finance-principles))
- [ ] Review sponsor ROI and satisfaction
- [ ] Assess volunteer performance
</Checklist>

### Documentation updates
<Checklist id="postevent-docs">
- [ ] Update sponsor database with new contacts and renewal notes (see [sponsorship/sponsor-lifecycle-and-fulfillment.md](../sponsorship/sponsor-lifecycle-and-fulfillment))
- [ ] Update volunteer list for future events
- [ ] Update vendor contact list (see [venue-and-logistics/vendor-and-contracts-tracker.md](../venue-and-logistics/vendor-and-contracts-tracker))
- [ ] Document lessons learned
- [ ] Update this documentation with improvements. This is not optional: a documentation set that doesn't absorb lessons learned decays into fiction
- [ ] Archive event materials for reference
</Checklist>

## Within 1 month

### Reporting
<Checklist id="postevent-reporting">
- [ ] Write comprehensive event report (see [post-event/event-report-guide.md](event-report-guide))
- [ ] Submit report to WordCamp Central
- [ ] Share report with sponsors
- [ ] Publish public summary for community
</Checklist>

### Financial closeout
<Checklist id="postevent-financial">
- [ ] Reconcile all expenses
- [ ] Process final vendor payments
- [ ] Close event bank account if applicable
- [ ] Prepare financial report
- [ ] Archive financial records
</Checklist>

Full detail: [planning/budget-and-finance-principles.md](../planning/budget-and-finance-principles).

## What "done" looks like

The post-event period is complete when: every thank-you has been sent, the report has been submitted to WordCamp Central, the books are reconciled, and this documentation has been updated with whatever the team learned. A WordCamp isn't over when the venue is locked. It's over when the next team can pick up this documentation and run the event better than this year's team did.
