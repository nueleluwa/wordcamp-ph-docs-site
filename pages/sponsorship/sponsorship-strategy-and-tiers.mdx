# Sponsorship Strategy & Tiers

> **What this is:** The reference for sponsorship tiers and pipeline stages.
>
> **What to do next:** Look up what each tier includes, then start outreach with the [Outreach Playbook](sponsorship-outreach-playbook).

**Purpose:** The reference tier structure and pipeline model for sponsorship. This is the lookup document. For the outreach process, see [sponsorship/sponsorship-outreach-playbook.md](sponsorship-outreach-playbook). For what happens after a sponsor says yes, see [sponsorship/sponsor-lifecycle-and-fulfillment.md](sponsor-lifecycle-and-fulfillment).

**Owner:** Sponsorship Lead
**Revenue target:** ₦10,000,000 (see [reporting-and-kpis/kpi-framework.md](../reporting-and-kpis/kpi-framework))

## Sponsorship tiers

| Tier | Amount (NGN) | Headline value |
|---|---|---|
| Platinum | ₦3,000,000 | Branded zone, first-choice booth, dedicated attendee email, impact report |
| Gold | ₦1,500,000 | Booth with power, camp-wide giveaway, attendee thank-you email |
| Silver | ₦750,000 | Shared table, tickets, story post |
| Community | ₦250,000 | Ticket, swag giveaway, option to sponsor student tickets |
| Individual | ₦25,000 | Ticket and a name on the sponsors page |
| In-kind | Value-matched | Recognition matched to the value supplied |

## What each tier includes

| Benefit | Platinum | Gold | Silver | Community |
|---|---|---|---|---|
| Included tickets | 8 | 5 | 3 | 1 |
| Speaker-dinner invitations | 2 | 1 | none | none |
| Booth or table | First-choice booth with power drop | Booth with power drop | Shared table | none |
| Branded zone (charging/Wi-Fi lounge, or lunch/coffee) | Yes | none | none | none |
| Reserved recruiting table / hiring announcement | Yes | Hiring announcement | none | none |
| Camp-wide giveaway on the main day | Yes | Yes | none | none |
| Swag at the registration table | Yes | Yes | Yes | 1 item |
| Own banner and printed handouts | Yes | Yes | Handouts | none |
| Dedicated email to attendees (opt-in list) | Yes | Logo in thank-you email | Logo in thank-you email | none |
| "Business story" blog post | Yes | Yes | Yes | Group thank-you post |
| Social media | Dedicated spotlight post | Dedicated post | Group thank-you post | Group thank-you post |
| Logo on website, signage and printed material | Largest | Large | Medium | Small |
| On-stage acknowledgement | Opening and closing | Closing | Closing | Closing |
| Post-event impact report | Full report | Summary | Summary | none |
| Sponsor student tickets (named in the impact report) | Optional | Optional | Optional | Optional |

**Individual (₦25,000):** one ticket, a name and link on the sponsors page, and inclusion in a group thank-you post.

**In-kind:** goods or services the event would otherwise pay for, such as venue, power, lunch, coffee, AV or printing. Value is set by Finance against a comparison quote, recognition follows the verified value on the tier ladder, and the terms are agreed in writing. See [In-Kind Sponsorship](in-kind-sponsorship).

<Callout type="warning">
  **Hard rule, not a guideline:** speaking slots are never sold or guaranteed by sponsorship tier, and no tier includes one. See [policies/wordcamp-central-compliance.md](../policies/wordcamp-central-compliance). A sponsor-affiliated speaker goes through the same review as any other speaker submission.
</Callout>

<Callout type="warning">

</Callout>

## Why these benefits

Logo placement alone doesn't justify a Nigerian sponsor's spend. Earlier WordCamp Lagos packages sold tickets, a booth for "engagement, recruiting, and networking", attendee emails, a business-story blog post, giveaways and speaker-dinner invitations. Sponsors also value things that solve local event problems, like reliable power at the booth and a charging or Wi-Fi lounge. Student tickets let sponsors show community impact.

## Pipeline stages

Sponsors move through a single pipeline, tracked on the Sponsorship dashboard (see [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup)):

1. **Prospect**: identified, not yet contacted
2. **Proposal Sent**: initial outreach sent
3. **In Discussion**: responded, negotiating
4. **Confirmed**: committed, invoice sent/paid

## Sponsorship KPIs

| KPI | Target | Measurement |
|---|---|---|
| Prospects Identified | 100 | Database count |
| Contact Rate | 80% | Contacted / Prospects |
| Response Rate | 30% | Responded / Contacted |
| Conversion Rate | 15% | Confirmed / Prospects |
| Average Deal Size | ₦1,000,000 | Revenue / Confirmed |
| Time to Close | 30 days | Days from contact to confirmed |

- **My Sponsors**: filtered by assigned team member
- **Follow-up Today**: filtered where Next Follow-up = today
- **Confirmed**: filtered where Status = Confirmed/Paid
- **Revenue Dashboard**: grouped by tier, summed amount
