# Master Planning Timeline

**Purpose:** The single, org-wide timeline from team formation to event day. Every team's detailed playbook nests inside this timeline — if a team's plan and this timeline ever disagree on timing, this document wins until updated.

**Owner:** Lead Organizer maintains this page; each Team Lead owns execution of their own rows.
**Where progress lives:** the Timeline database in the shared dashboard — see [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup). This document is the reference; the dashboard is the live tracker.

Adjust all dates relative to your confirmed event date.

## 9 Months Before

- [ ] Form core organizing team and assign Team Leads
- [ ] Set tentative event date
- [ ] Create initial budget estimate — see [planning/budget-and-finance-principles.md](budget-and-finance-principles)
- [ ] Research potential venues
- [ ] Submit WordCamp application to WordCamp Central
- [ ] Set up communication channels (Slack/WhatsApp/Email)
- [ ] Create project management workspace — see [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup)
- [ ] Begin sponsor prospect list development

## 8 Months Before

- [ ] Receive WordCamp Central approval
- [ ] Finalize event date
- [ ] Confirm venue and sign contract *(sign-off owner: see [organisation/open-decisions-and-gaps.md](../organisation/open-decisions-and-gaps))*
- [ ] Set up WordCamp website (provided by WordCamp Central)
- [ ] Create sponsor prospectus/deck — see [sponsorship/sponsorship-strategy-and-tiers.md](../sponsorship/sponsorship-strategy-and-tiers)
- [ ] Begin sponsor outreach
- [ ] Recruit additional organizers — see [recruiting/organizer-recruitment-sop.md](../recruiting/organizer-recruitment-sop)

## 7 Months Before

- [ ] Continue sponsor outreach (target 20 contacts/week)
- [ ] Begin partnership & outreach campaigns to schools, training hubs, corporates, communities — see [partnerships-and-outreach/](../partnerships-and-outreach/)
- [ ] Plan event schedule structure
- [ ] Research and contact potential speakers
- [ ] Create marketing plan and content calendar — see [marketing-and-communications/content-and-articles-guide.md](../marketing-and-communications/content-and-articles-guide)
- [ ] Design initial branding materials

## 6 Months Before

- [ ] Open Call for Speakers — see [speakers-and-program/call-for-speakers-and-program-guide.md](../speakers-and-program/call-for-speakers-and-program-guide)
- [ ] Continue sponsor follow-ups
- [ ] Begin social media promotion
- [ ] Finalize catering vendor selection
- [ ] Plan swag and merchandise
- [ ] Create volunteer recruitment plan — see [volunteers/volunteer-program-guide.md](../volunteers/volunteer-program-guide)

## 5 Months Before

- [ ] Review speaker applications
- [ ] Begin speaker selection process
- [ ] Continue sponsor negotiations
- [ ] Finalize event schedule
- [ ] Order swag and merchandise
- [ ] Create registration/ticketing system

## 4 Months Before

- [ ] Confirm first batch of speakers
- [ ] Announce keynote speakers publicly
- [ ] Open ticket sales
- [ ] Continue sponsor outreach for remaining slots
- [ ] Begin volunteer recruitment
- [ ] Plan workshop sessions
- [ ] Order printing for banners and signage

## 3 Months Before

- [ ] Confirm all speakers
- [ ] Publish full event schedule
- [ ] Ramp up social media promotion
- [ ] Send speaker information packets
- [ ] Confirm sponsor logos and benefits
- [ ] Process volunteer applications
- [ ] Plan networking/social events

## 2 Months Before

- [ ] Send speaker reminders and collect final materials
- [ ] Confirm all sponsor deliverables
- [ ] Assign volunteers to roles and shifts
- [ ] Conduct venue walkthrough with key organizers
- [ ] Finalize AV requirements
- [ ] Create event day runbook — see [event-day/operations-runbook.md](../event-day/operations-runbook)
- [ ] Plan photographer/videographer coverage

## 1 Month Before

- [ ] Confirm all logistics (catering, AV, security) — see [venue-and-logistics/nigerian-logistics-checklist.md](../venue-and-logistics/nigerian-logistics-checklist)
- [ ] Print badges and signage
- [ ] Prepare registration desk materials
- [ ] Conduct volunteer training session
- [ ] Send final attendee information email
- [ ] Confirm speaker travel arrangements
- [ ] Prepare sponsor booth assignments
- [ ] Test all AV equipment
- [ ] Final venue walkthrough

## 2 Weeks Before

- [ ] Final headcount for catering
- [ ] Print final schedules and materials
- [ ] Confirm all vendor deliveries
- [ ] Send final details to speakers
- [ ] Prepare emergency contact list
- [ ] Pack organizer toolkit and supplies

## 1 Week Before

- [ ] Final team meeting with all organizers
- [ ] Confirm volunteer assignments
- [ ] Test backup systems (generator, internet)
- [ ] Prepare day-of-event communication plan
- [ ] Send reminder email to all attendees
- [ ] Confirm transportation for speakers
