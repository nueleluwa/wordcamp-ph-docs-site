# How to Use This Documentation

**Purpose:** Explain the structure so anyone — including someone who never saw the original planning documents — can navigate this without help.

## The standard for every document

Every guide and SOP in this repository is written to answer the same eight questions. If a document doesn't answer one of these, treat that as a gap to raise, not something to guess at:

1. **What am I responsible for?**
2. **What do I need to do?**
3. **When do I need to do it?**
4. **Who do I work with?**
5. **What does success look like?** (usually a link to [reporting-and-kpis/kpi-framework.md](../reporting-and-kpis/kpi-framework))
6. **Where do I record my progress?** (usually a link to [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup))
7. **What happens if I can't complete it?**
8. **Who do I escalate to?** (see [organisation/accountability-and-escalation.md](../organisation/accountability-and-escalation))

## Navigating by role, not by folder

You do not need to read this documentation top to bottom. Find your team in [organisation/team-structure-and-roles.md](../organisation/team-structure-and-roles), then read only:

1. Your team's playbook (e.g. [sponsorship/](../sponsorship/))
2. [planning/weekly-operating-rhythm.md](../planning/weekly-operating-rhythm) — how reporting and meetings work
3. [reporting-and-kpis/](../reporting-and-kpis/) — how your progress is tracked
4. [event-day/](../event-day/) — closer to the event

Everything else is reference material you dip into when needed, not required reading.

## Templates vs. playbooks

Playbooks (in team folders) explain **how and why**. Templates (in [templates/](../templates/)) are the **blank documents you actually fill in** — application forms, weekly reports, tracking sheets. If you're looking for a form to send someone or fill out yourself, go straight to `templates/`.

## Conventions used throughout

- `- [ ]` marks a checklist item to complete in order.
- Tables marked "Target / Current / Owner" are meant to be copied into the live dashboard, not tracked by hand in a document — see [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup).
- `[Bracketed text]` in any template means "replace this before sending or using."
- A document under [organisation/open-decisions-and-gaps.md](../organisation/open-decisions-and-gaps) means the team has not yet settled that question — don't treat silence on it as an answer.
