# Glossary & Key Terms

| Term | Meaning |
|---|---|
| WCPHC | WordCamp Port Harcourt |
| Official email | portharcourt@wordcamp.org — the organization's official contact address (see [00-start-here/welcome-and-philosophy.md](welcome-and-philosophy)) |
| WordCamp Central | The global body governing all WordCamps under the WordPress Foundation |
| CFP | Call for Speakers — the open submission process for talks |
| COC | Code of Conduct — see [policies/code-of-conduct-and-safety.md](../policies/code-of-conduct-and-safety) |
| Lead Organizer | The organizer accountable for overall event outcomes; chairs the command center on event day |
| Team Lead | The organizer accountable for one functional team's KPIs and deliverables (e.g. Sponsorship Lead, Logistics Lead) |
| Pipeline | The staged tracking of prospects moving toward a confirmed outcome (sponsor pipeline, partnership pipeline) — see each team's playbook |
| Tier | A named level of sponsorship or partnership commitment with defined benefits (Platinum/Gold/Silver/Community for sponsors; Champion/Advocate/Supporter/Friend for communities) |
| Break-even | The financial target: total revenue (tickets + sponsorship) at least covers total expenses |
| Command Center | The physical/coordination point on event day where Lead Organizer, Logistics Lead, Volunteer Coordinator, and Program Lead make real-time decisions |
| Ambassador | A recruited student who promotes WCPHC on their campus in exchange for a free ticket and swag — see [partnerships-and-outreach/school-and-university-outreach.md](../partnerships-and-outreach/school-and-university-outreach) |
| Dashboard | The live, continuously-updated tracking view (Notion or equivalent) — not a static document. See [reporting-and-kpis/dashboard-and-tracking-setup.md](../reporting-and-kpis/dashboard-and-tracking-setup) |
