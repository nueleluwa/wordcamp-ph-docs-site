## If you need to drop a shift

Notify the Volunteer Coordinator as early as possible. See "Volunteer commitment" in the [Volunteer Program Guide](/volunteers/volunteer-program-guide). A shift quietly left uncovered is exactly what this documentation is built to prevent.
