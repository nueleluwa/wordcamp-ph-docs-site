# Event Day

The runbook and issue response playbook for running the event itself.

### [Event Day Operations Runbook](event-day/operations-runbook)
Step-by-step instructions for running event day. Share it with every organizer and team lead, so everyone on-site knows what happens when and who is where. If something goes wrong, see the issue response playbook.

### [Issue Response Playbook](event-day/issue-response-playbook)
A pre-agreed response and owner for the problems most likely to come up on event day, so nobody has to improvise in the moment. This is the event-day version of accountability-and-escalation.
