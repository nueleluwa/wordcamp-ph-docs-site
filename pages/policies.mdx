# Policies

The rules WCPH must follow, including WordCamp Central compliance and Code of Conduct.

### [WordCamp Central Compliance](policies/wordcamp-central-compliance)
The rules WCPH must follow because it operates under WordCamp Central and the WordPress Foundation, not because the local team chose them. These are not negotiable at the local level — if a decision anywhere in this documentation seems to conflict with one of these, the rule below wins and the document should be corrected.

### [Code of Conduct & Safety](policies/code-of-conduct-and-safety)
An "open to all" event with 150–400 attendees, volunteers, speakers, and sponsors needs a working answer to "what happens if someone is harassed or made unsafe," before it needs the answer, not after. Attendee, speaker, and volunteer application/registration flows referenced throughout this documentation (see recruiting/, attendee-communications) should link to whatever COC is formally adopted.
