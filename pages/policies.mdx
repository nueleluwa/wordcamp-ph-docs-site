# Policies

The rules WCPHC must follow, including WordCamp Central compliance and the Code of Conduct.

### [WordCamp Central Compliance](policies/wordcamp-central-compliance)
The rules WCPHC must follow because it operates under WordCamp Central and the WordPress Foundation, not because the local team chose them. They aren't negotiable at the local level. If a decision anywhere in this documentation seems to conflict with one of these rules, the rule wins and the document should be corrected.

### [Code of Conduct & Safety](policies/code-of-conduct-and-safety)
An event open to everyone, with 500–1,000+ attendees, volunteers, speakers, and sponsors, needs a working answer to "what happens if someone is harassed or made unsafe" before it needs the answer, not after. Every application and registration flow in this documentation (see recruiting/, attendee-communications) should link to whichever Code of Conduct gets formally adopted.
