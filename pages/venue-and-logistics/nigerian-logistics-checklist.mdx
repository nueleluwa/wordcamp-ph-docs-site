# Nigerian Logistics Checklist

<PageInfo
  purpose="Addresses the specific logistical realities of running an event in Nigeria — this is not a generic event checklist with local color added; power, internet, and transportation are planned for as first-class requirements from the start."
  owner="Logistics Lead"
  prerequisites={<>Run this in full during the "1 Month Before" and "2 Weeks Before" milestones of the <a href="../planning/master-planning-timeline">Master Planning Timeline</a>.</>}

Verify every backup system again during setup day — see [event-day/operations-runbook.md](../event-day/operations-runbook).

## Power & electricity

<Checklist id="logistics-power">
- [ ] Confirm venue has reliable power supply
- [ ] Arrange backup generator (specify capacity needed)
- [ ] Test generator before event day
- [ ] Ensure adequate fuel for generator
- [ ] Have UPS systems for critical equipment (projectors, sound system)
- [ ] Provide power strips/extension cords for attendees
- [ ] Label power outlets clearly
</Checklist>

## Internet connectivity

<Checklist id="logistics-internet">
- [ ] Confirm venue internet bandwidth (minimum 50 Mbps recommended)
- [ ] Arrange backup internet (multiple ISPs if possible)
- [ ] Set up dedicated WiFi network for organizers/speakers
- [ ] Create separate WiFi network for attendees
- [ ] Print WiFi credentials on signage
- [ ] Test connectivity in all rooms before event
- [ ] Have mobile hotspots as emergency backup
</Checklist>

## Venue & facilities

<Checklist id="logistics-venue">
- [ ] Confirm venue capacity matches expected attendance
- [ ] Verify parking availability and capacity
- [ ] Check accessibility for persons with disabilities
- [ ] Confirm restroom facilities are adequate and clean
- [ ] Arrange security personnel for venue
- [ ] Confirm venue insurance coverage
- [ ] Get emergency exit routes and procedures
- [ ] Arrange first aid kit and identify nearest hospital
</Checklist>

## Catering & refreshments

<Checklist id="logistics-catering">
- [ ] Select catering vendor with event experience
- [ ] Confirm menu options
- [ ] Collect dietary restrictions from attendees during registration
- [ ] Arrange water stations throughout venue
- [ ] Plan coffee/tea service for morning sessions
- [ ] Schedule lunch break appropriately
- [ ] Confirm food delivery timing
- [ ] Have backup food vendor contact
</Checklist>

## Transportation & logistics

<Checklist id="logistics-transport">
- [ ] Create venue location map with landmarks
- [ ] Arrange shuttle service if venue is remote
- [ ] Share public transportation options with attendees
- [ ] Coordinate speaker airport pickups if needed
- [ ] Plan for traffic delays in Port Harcourt
- [ ] Provide clear directions in all communications
</Checklist>

## Registration & check-in

<Checklist id="logistics-registration">
- [ ] Set up registration desk with clear signage
- [ ] Print attendee badges in advance
- [ ] Prepare check-in spreadsheet/system
- [ ] Have backup paper registration list
- [ ] Arrange queue management (ropes/stanchions)
- [ ] Prepare swag bags for distribution
- [ ] Set up volunteer briefing for registration team
</Checklist>

## Audio/visual equipment

<Checklist id="logistics-av">
- [ ] Confirm projector and screen in each session room
- [ ] Test microphone and sound system
- [ ] Provide HDMI/VGA adapters for speakers
- [ ] Set up speaker timer/clock
- [ ] Arrange video recording equipment if applicable
- [ ] Test live streaming setup if applicable
- [ ] Have backup equipment on standby
</Checklist>

## Signage & branding

<Checklist id="logistics-signage">
- [ ] Design and print directional signage
- [ ] Create room identification signs
- [ ] Print sponsor banners and displays
- [ ] Prepare schedule/agenda posters
- [ ] Create WiFi information signs
- [ ] Print emergency contact information
- [ ] Arrange for sponsor booth signage
</Checklist>
